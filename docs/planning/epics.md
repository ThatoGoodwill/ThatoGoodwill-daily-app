# Epics — PipelinePal

- **Boards & Cards** — Core Board → Column → Card model: create/view/edit applications, move cards between pipeline stages.
- **Auth** — Basic sign-up/login so a user's board is private to them.
- **Reminders** — Follow-up nudges for applications sitting untouched in a stage past a set number of days.
- **Notes & Attachments** — Per-card notes (interview prep, contacts) and links/files (resume version, job posting).
- **Reporting** — Simple stats view: applications sent, response rate, time-in-stage.
