## PipelinePal — Sprint 1 Review

Sprint Goal:

 By the end of this sprint, I can log a job application and see it appear on a real board, end to end — from having a data model, to a board with default columns, to a working card I can add, view, and edit.

## Was the Sprint Goal achieved?

Partially. The board half of the goal is real and working: the data model exists, is written down, and a board genuinely creates itself with the four default columns (Applied, Interviewing, Offer, Rejected) when I click "Create Board." I verified this myself in the browser, not just in the code.

The "log a job application" half is not yet done. I have not finished the add-card, view-cards, or edit-card stories, so the goal as originally written — a full application logged and visible end to end — has not been reached this sprint.

## What's actually demoable right now

Click "Create Board" → a board appears with exactly the four correct columns, in the correct order, with nothing extra.
The underlying data model (createBoard, createCard) is written, testable, and confirmed working in the browser console.

## What is NOT demoable yet

Adding a card to a column (in progress, not yet built)
Viewing all cards in a column (not started)
Editing an existing card's details (not started, subtasks not yet begun)

## Honest assessment

Two of five Sprint 1 stories are genuinely Done, verified by hand, not just marked done. The other three are still To Do. The sprint under-delivered against its own goal, but what is done is done for real — no story was marked complete without me clicking through it myself first.
